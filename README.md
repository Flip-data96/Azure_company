# 📊 Azure Company Dashboard

Projeto de Business Intelligence desenvolvido de ponta a ponta, contemplando a criação do banco de dados em ambiente cloud (Azure), modelagem relacional, integração com Power BI, desenvolvimento de métricas em DAX e construção de um dashboard executivo para análise de indicadores de Recursos Humanos.

## Arquitetura da Solução

```text
SQL Scripts
     │
     ▼
Azure Database for MySQL
     │
     ▼
Power BI Desktop
(Modelagem + DAX)
     │
     ▼
Dashboard Executivo
```

## Principais Etapas do Projeto

- Criação e hospedagem do banco de dados MySQL na Azure
- Modelagem relacional e definição de chaves primárias e estrangeiras
- Integração entre Azure MySQL e Power BI
- Tratamento de inconsistências na importação utilizando consultas SQL nativas
- Modelagem dos relacionamentos no Power BI
- Desenvolvimento de medidas e colunas calculadas em DAX
- Construção do dashboard com foco em indicadores de Recursos Humanos

---

## Métricas Desenvolvidas

- Total de Funcionários
- Folha Salarial
- Média Salarial
- Nome Completo (coluna calculada)
- Horas Trabalhadas por Projeto
- Funcionários por Departamento

## Principais Visualizações

- Colaboradores por Gênero
- Dependentes por Relação
- Horas por Projeto
- Matriz de Horas por Funcionário e Projeto

---

## Desafios Resolvidos

Durante o desenvolvimento foram solucionados problemas comuns em projetos de BI, como:

- Integração entre Azure Database for MySQL e Power BI
- Importação de tabelas vazias utilizando consultas SQL nativas
- Ajuste de relacionamentos e cardinalidades
- Correção de caminhos ambíguos no modelo de dados
- Criação de medidas e colunas calculadas em DAX
